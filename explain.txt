--------------------------------------------------
WHAT IS AN MCP SERVER? (Simple Definition)
--------------------------------------------------
Normally, an AI like ChatGPT or Claude only knows what it learned from
the internet, up to a certain date. It CANNOT look at:
- Your private GitHub repos
- Your personal Notion notes
- Files on your own computer
- Any private company database

An MCP (Model Context Protocol) Server is like a SAFE DOOR you build
that lets the AI peek into ONE specific private place - but only in the
ways YOU allow.

You decide exactly what the AI can see and do. Nothing more.

--------------------------------------------------
REAL WORLD EXAMPLE
--------------------------------------------------
Imagine you're a manager, and every morning you ask your assistant:

  "Hey, what issues are open in our project repo right now?"

Without an MCP server:
  Your assistant (the AI) has NO idea. It has never seen your GitHub
  account. It would have to guess or say "I don't know, I can't check
  that."

With an MCP server:
  You ask the same question. This time, the AI:
  1. Realizes it needs live GitHub data
  2. Calls your MCP server's "get_open_issues" tool
  3. Your server fetches real, live data from GitHub
  4. The AI reads it and replies:
     "You have 7 open issues. 3 are marked urgent - #45 (login bug),
      #52 (payment crash), #61 (broken signup form)."

That's a REAL, USEFUL answer, using YOUR real private data - safely.

--------------------------------------------------
ANOTHER EXAMPLE - WHY THE SAFETY RULE MATTERS
--------------------------------------------------
Say you ask: "Close all issues older than 30 days."

This is a DESTRUCTIVE action (it changes/deletes real data). A well
built MCP server will NOT just do it silently. It will say:

  "I found 12 issues older than 30 days. Do you want me to close all
   of them? (yes/no)"

Only after you say "yes" does it actually make the change. This
protects you from the AI making a mistake that can't be undone.

--------------------------------------------------
WHY THIS PROJECT MATTERS FOR YOUR PORTFOLIO
--------------------------------------------------
1. It proves you understand HOW AI tools actually work behind the
   scenes - not just how to write a prompt.

2. It shows you think about SAFETY - you separated "safe to run
   automatically" actions from "needs human approval" actions.

3. It's measurable - you can show real numbers in an interview:
   "I tested my server with 50 different questions. The AI picked the
    right tool 94% of the time. When it failed, it was usually because
    my tool's description was unclear - so I improved the description

   This tells an interviewer: "This person doesn't just build things,
   they TEST and IMPROVE things." That's a senior-level habit, not
   junior-level.

--------------------------------------------------
IN ONE SENTENCE
--------------------------------------------------
An MCP Server is a safe, custom-built bridge that lets an AI securely
read (and carefully act on) your private data - like a translator and
security guard standing between the AI and your real systems.
